# دفتر الكريدي — Daftar Al Kredi

تطبيق أندرويد عربي لإدارة ديون الزبائن، الكاشير ومسح الباركود، مكتبة المنتجات، الإحصائيات والحاسبة. البيانات الأساسية تحفظ محلياً في SQLite عبر Room، ولا يحتاج التطبيق إلى حساب أو خادم أو إنترنت أثناء الاستخدام.

## التقنيات

- Kotlin + Jetpack Compose + Material 3
- Room / SQLite
- MVVM باستخدام ViewModel و StateFlow
- CameraX + Google ML Kit لقراءة الباركود بالكاميرا
- Coil لعرض صور المنتجات
- Android Storage Access Framework للنسخ الاحتياطي والاستعادة

## فتح المشروع

1. فك ضغط المشروع وافتح مجلد `daftar-al-kredi` في Android Studio Ladybug (2024.2.1) أو أحدث.
2. ثبّت Android SDK Platform 35 وBuild Tools 35.0.0 عند طلب Android Studio ذلك.
3. استخدم JDK 17 عند مزامنة Gradle.
4. وافق على تنزيل Gradle والمكتبات عند أول مزامنة. يلزم اتصال إنترنت لأول بناء فقط لتنزيل أدوات البناء والمكتبات. بعد تثبيتها، يعمل التطبيق نفسه دون إنترنت.
5. اضغط **Sync Project with Gradle Files** ثم **Run** لتشغيله على هاتف أو محاكي Android 6.0/API 23 أو أحدث.

## بناء APK محلياً

على Windows افتح CMD في مجلد المشروع ونفّذ:

```bat
gradlew.bat --no-daemon :app:assembleDebug
```

على Linux أو macOS:

```bash
chmod +x gradlew
./gradlew --no-daemon :app:assembleDebug
```

ملف APK الناتج:

`app/build/outputs/apk/debug/app-debug.apk`

السكربتان `gradlew` و`gradlew.bat` ينزّلان Gradle 8.9 تلقائياً عند أول تشغيل، لذلك لا تحتاج إلى تثبيت Gradle يدوياً.

## البناء على GitHub Actions

1. أنشئ مستودعاً جديداً على GitHub باسم `daftar-al-kredi`، ثم افتح Terminal داخل هذا المجلد.
2. نفّذ الأوامر التالية بعد استبدال رابط المستودع برابط مستودعك:

```bash
git init
git add .
git commit -m "Initial Daftar Al Kredi app"
git branch -M main
git remote add origin https://github.com/USERNAME/daftar-al-kredi.git
git push -u origin main
```

3. افتح تبويب **Actions** في GitHub وشاهد مهمة **Build Daftar Al Kredi APK**.
4. بعد نجاحها، افتح نتيجة التشغيل ثم نزّل Artifact باسم `daftar-al-kredi-debug-apk`. ستجد داخله `app-debug.apk`.

كل Push إلى `main` أو `master` يشغّل بناءً تلقائياً. ويمكن تشغيله يدوياً من **Actions → Build Daftar Al Kredi APK → Run workflow**.

## طريقة عمل الكاشير والباركود

- افتح تبويب **الكاشير** ثم اضغط **مسح باركود** واسمح باستخدام الكاميرا.
- عند مسح باركود غير محفوظ، يطلب التطبيق اسم المنتج وسعره، ويمكنك تصوير المنتج بالكاميرا أو اختيار صورته من المعرض. بعد الحفظ يضاف المنتج مباشرة إلى الفاتورة، ثم يعود الماسح لانتظار المنتج التالي.
- عند مسح الباركود نفسه لاحقاً، يتعرف التطبيق على المنتج ويضيفه للفاتورة دون إعادة إدخال الاسم والسعر.
- يمكن أيضاً إضافة منتج يدوياً أو فتح مكتبة المنتجات واختيار منتج محفوظ.
- عدّل الكمية من أزرار + و−، ثم اضغط **إضافة الإجمالي كدين على زبون** واختر الزبون. تُسجّل الفاتورة كعملية دين في كشف حسابه.

## ميزات الإصدار

- قائمة زبائن مع بحث فوري وفرز حسب الاسم أو أكبر دين أو آخر عملية، ويظهر الرصيد بجانب كل اسم.
- سجل الدين والدفعات مع إمكانية تعديل العملية أو حذفها.
- كشف حساب نصي قابل للمشاركة وPDF.
- اتصال سريع وفتح محادثة WhatsApp عند توفر رقم الهاتف.
- إحصائيات أسبوعية وشهرية ومخصصة، وأكبر خمسة مدينين ورسم يومي مبسط.
- حاسبة منتجات وكاشير، وآلة حاسبة عادية.
- ألوان: أبيض، أسود، أخضر نعناعي، برتقالي، أزرق بحري، وعملة قابلة للتغيير.
- قفل برمز PIN.
- نسخ احتياطي واستعادة لبيانات الزبائن والعمليات والمنتجات بصيغة JSON.

## ملاحظات مهمة

- لا ترسل التطبيق بياناتك إلى أي خادم. قاعدة البيانات محلية على الهاتف.
- النسخ الاحتياطي JSON يتضمن سجلات المنتجات وصور المنتجات نفسها بصيغة Base64، لذلك يمكن استعادة الصور على هاتف آخر أيضاً. احفظ ملف النسخة في مكان آمن لأنه قد يكبر حسب عدد الصور.
- قفل PIN حماية وصول بسيطة داخل التطبيق، وليس تشفيراً لملف قاعدة البيانات.
- ملف GitHub Actions الناتج هو Debug APK للتجربة والتثبيت. للنشر في Google Play أنشئ توقيع Release بمفتاحك الخاص ولا ترفع keystore إلى GitHub.
